# Cordoval Day Rate

Privacy-first day rate calculator for [day-rate.cordoval.co.uk](https://day-rate.cordoval.co.uk).

Work out your freelance day rate from the income you want to keep, your business costs, and billable days. All calculations run in the browser. Nothing is stored.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Static output is in `dist/`, ready for Vercel or any static host.
